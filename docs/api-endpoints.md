# API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| POST | /auth/register | Register a new user |
| POST | /auth/login | Authenticate user |
| GET | /wallet/balance | Get wallet balance |
| POST | /wallet/add-funds | Add funds to wallet |
| GET | /recommendations | Get current BUY/SELL recommendations |
| POST | /trade/buy | Place a buy order |
| POST | /trade/sell | Place a sell order |
| GET | /positions | Get user's current positions |
| GET | /stocks | List tracked stocks |
